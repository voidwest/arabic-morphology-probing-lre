# Supporting paper artifacts

This directory contains the preserved alpha-sensitivity and paired-location
bootstrap outputs cited by the manuscript as supporting analysis artifacts.
The primary completed BF16 matrix and its authoritative validation records are
under `evidence/bf16-analysis-20260826-v2/snapshot/analysis/`.

The historical Q8 inputs referenced in some metadata are intentionally
external to this public archive. The files here are retained because they are
part of the paper's reported supporting evidence; they are not required for a
new BF16 extraction run.
